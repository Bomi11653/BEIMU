## 图片策略

详情图片转为无损 WebP，保持原始像素尺寸和内部设计；封面为独立缩略副本。详情采用连续单列、原比例展示，避免海报被高度限制缩小到难以阅读。大图懒加载。

分类首页代表项目指定为汉堡，封面读取该项目 `cover`。原有 3D/视频项目版式不受新 `galleryLayout: sequence` 影响。
