# BEIMU 首页开发计划

## 已确认的视觉方向

- 单页全屏作品集，固定为 `100dvh`，无纵向滚动。
- 方案 2：大画幅视频背景、顶部居中细长玻璃分段导航、左下身份信息。
- 主标题：郑荣成；品牌副标题：BEIMU。
- 三项能力顺序：3D 建模项目 → AI 开发项目 → 新媒体视频运营师。
- 字体：Inter Variable + Noto Sans SC Variable，均为开源字体并随项目打包。
- 视觉效果只使用底部遮罩模糊，不叠加黑色渐变压暗。

## 阶段拆分

### P1 — 结构与视觉底座

- 建立 Next.js 16、React 19、TypeScript、Tailwind CSS 4 工程。
- 完成一屏布局、玻璃导航、身份区和底部元信息。
- 使用真实 3D 作品视频作为默认背景。
- 导航支持选中态，为下一阶段的视频切换预留数据结构。

### P2 — 视频状态与过渡

- 建立 3D、AI、新媒体三类媒体清单。
- 鼠标悬停或键盘聚焦时切换对应视频。
- 双视频层交叉淡入淡出，避免重新加载时闪黑。
- 默认按 3D → AI → 新媒体顺序自动播放，并在用户交互后暂停自动轮播。
- AI 分类内交替展示 dbsource-pro 与 yuyakang 两段站点预览。

### P3 — 跳转与内容接入

- AI 项目接入 `https://www.dbsource-pro.com/` 与 `https://www.yuyakang.top/`。
- 新媒体分类接入案例视频及账号主页链接。
- 3D 分类补充作品详情入口或作品集集合页。
- 增加触屏设备的点击逻辑和明确的当前状态提示。

### P4 — 性能、无障碍与上线准备

- 视频转码为桌面与移动端不同码率，并生成 poster。
- 补齐键盘导航、对比度、减少动态效果与加载失败降级。
- 进行 Lighthouse、真实设备和主流浏览器测试。
- 配置正式域名、Open Graph 信息与部署环境。
